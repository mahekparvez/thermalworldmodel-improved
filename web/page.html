Does error grow with horizon?

The failure mode that matters in a rollout model is drift — error that compounds as the model is left alone. This is why training used multi-step rollouts with an explicit drift penalty rather than single-step loss, which on 2 Hz thermal data is trivially easy and hides exactly this.

The physics model's error grows with horizon; the network's flattens. That is the one place the extra parameters clearly paid for themselves.

Identified parameters

Fourteen parameters were fitted against measured data, bounded by physically plausible ranges. Capacitances (from m·c_p), the copper temperature coefficient, and every published material property were held fixed — fitting a knowable constant to improve a residual destroys the only ground truth a model has.

Four parameters hit their bounds — the structure is imperfect

A parameter that had to reach its limit to fit the data means the model structure is wrong, not the parameter. All four point the same way: the model cannot generate enough speed-driven loss. Iron hysteresis and bearing friction pinned high, phase resistance pushed 2.3× down, magnet eddy up 5×, and the AC-copper coefficient moved off zero.

The most likely single cause is pole_pairs, which is unsourced — it is not published with the dataset. Electrical frequency enters the eddy term quadratically, so one wrong integer would produce exactly this signature. It is also the cheapest thing to fix.

What the network learned, in physical units

Because the network keeps the thermal network's structure, everything it learned is a conductance or a capacitance in real units — and can be put beside the physics model's values. A black box offers no such check.

The two disagree most on the housing capacitance — which is the one node that is never measured. It is a latent state, seeded from the coolant, and its identified value should be trusted least.

Only the reality gate can falsify the physics. The other two confirm the code is self-consistent — necessary, but they would pass just as happily on a model that describes no real motor.

What this cannot do

  • 3 K mean is not a safety margin. Peak errors reach 25 K (physics) and 30 K (network) on the magnet.
  • The housing is never measured and the stator tooth is measured but not modelled — a four-node network lumps it into the yoke.
  • Coolant flow rate is not in the dataset. The flow-dependent resistance law is implemented and unit-tested but never exercised against data, so any claim about pump degradation is untested.
  • One machine. Everything is fitted to a single prototype PMSM. Nothing here demonstrates transfer — and transfer is the whole claim of a "world model".
  • Geometry is assumed, not taken from drawings, which are not published.
